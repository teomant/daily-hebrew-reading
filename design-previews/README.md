# Design previews

Open `index.html` in a browser and select a direction. The neutral toolbar above each prototype switches among:

- all four visual directions;
- Home, Archive, Day, and Article pages;
- desktop and mobile viewport previews.

The article page keeps one lexical translation popover visible so its placement and visual weight can be compared. All content, controls, and imagery are representative only; these files are disposable design prototypes and are not the production frontend.

## Directions

1. **Jerusalem Journal** — editorial, literary, restrained, with traditional magazine hierarchy.
2. **Clear Study** — spacious, modern, and optimized around reading and learning controls.
3. **Café Notebook** — warm, approachable, and human, with Mediterranean colors and softer shapes.
4. **Tel Aviv Grid** — bold, urban, graphic, and distinctly digital.

After a direction is selected, its visual system—not this prototype's markup—will guide the production implementation.
