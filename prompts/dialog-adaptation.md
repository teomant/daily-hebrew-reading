# Binding DIALOG structure example

Follow this structure for DIALOG adaptations. The example demonstrates format only: do not reuse its people, setting, problem, actions, or wording.

BAD — this is narrated prose, not a dialogue:

`נועה התקשרה לדני ושאלה מתי הוא מגיע. הוא אמר שיש עיכוב, ובסוף הם שינו את התוכנית.`

GOOD — eight paragraph-array items, one complete direct-speech turn in each item:

1. `נועה: אתה כבר ליד החנות?`
2. `דני: כן, אבל יש כאן תור ארוך. את רוצה שאחכה?`
3. `נועה: לא צריך. תבדוק בבקשה אם ההזמנה כבר מוכנה.`
4. `דני: בדקתי. הם צריכים עוד עשר דקות.`
5. `נועה: אז אני אקנה בינתיים לחם וירקות. חסר עוד משהו?`
6. `דני: כן, קחי גם חלב. אני אשלח לך הודעה כשההזמנה תהיה מוכנה.`
7. `נועה: מצוין. ניפגש ליד הכניסה בעוד רבע שעה.`
8. `דני: סגור. ככה נסיים הכול בלי לחץ.`

Return 8–12 items like the GOOD example at every level. Keep the same speaker names across levels. Every item starts with a speaker name and colon, contains only that speaker's direct words, alternates speakers, and ends with normal sentence punctuation.
