# Adaptation and annotation instructions

Write modern spoken Israeli Hebrew: natural language a contemporary adult might use to tell, ask, answer, clarify, or explain something to another person. Favor reusable conversational sentences over news-style narration. Avoid biblical, religious, literary, bureaucratic, specialist, and dense newspaper language. Do not use niqqud. Keep one central idea and develop it with useful situation details, interaction, and outcome; never repeat sentences merely to reach a word target.

Create every configured reading level from the same factual or scenario brief. The complete daily issue should provide roughly 40–50 minutes of learner reading at every level. Aim close to each level's targetWords and normally stay within its minimumWords and maximumWords. Write 4–5 real paragraphs per article, with multiple sentences in most paragraphs; do not collapse the material into a three-sentence summary or use one sentence per paragraph. Easier versions may omit detail; harder versions may add natural dialogue, reasons, reactions, and consequences already supported by the brief, but facts, event order, and outcome must remain consistent. Write and proofread each version as continuous Hebrew prose before any lexical annotation is attempted.

During the segmentation phase, treat the supplied Hebrew prose as immutable. Segment every title, teaser, and paragraph into useful lexical units without changing a character, word, prefix, space, punctuation mark, or word order. A unit may be a word, fixed expression, multi-word construction, or proper noun. Preserve expressions such as מזג אוויר, שם לב, and בסופו של דבר as single units when splitting would harm understanding. Punctuation and whitespace are separator units. Include every original whitespace character as a separator. Never return a lexical unit with an empty `text` value; omit it instead.

Translate every meaningful unit in every configured translation language whenever a useful translation exists. Read the whole sentence before translating a unit. Translate its contextual meaning and grammatical role—including attached Hebrew prefixes, tense, reference, and idiomatic meaning—not merely its isolated dictionary form. Use an empty string only when the unit genuinely has no useful direct translation in context; never stop translating because enough other units have translations. Separators have empty translations.

Return only data matching the supplied schema. Use ASCII lowercase kebab-case slugs. Teasers must be one concise sentence. Prefer several short paragraphs. Do not put Markdown or HTML in content fields.
