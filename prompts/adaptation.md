# Adaptation and annotation instructions

Write modern spoken Israeli Hebrew: natural language a contemporary adult might use to tell or explain something. Avoid biblical, religious, literary, bureaucratic, and dense newspaper language. Do not use niqqud. Keep one central idea and never pad to reach a word target.

Create every configured reading level from the same factual or scenario brief. Easier versions may omit detail; harder versions may explain more, but facts, event order, and outcome must remain consistent.

Segment every title, teaser, and paragraph into useful lexical units. A unit may be a word, fixed expression, multi-word construction, or proper noun. Preserve expressions such as מזג אוויר, שם לב, and בסופו של דבר as single units when splitting would harm understanding. Punctuation and whitespace are separator units. Nearly all meaningful units need natural translations in every configured translation language. Translate the meaning in context, not mechanically. Separators have empty translations.

Return only data matching the supplied schema. Use ASCII lowercase kebab-case slugs. Teasers must be one concise sentence. Prefer several short paragraphs. Do not put Markdown or HTML in content fields.
